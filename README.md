# المرشد التعليمي لكتابة الإطار العام للدراسة

تطبيق Streamlit باللغة العربية لتعليم الطالب كيفية بناء عناصر الإطار العام للدراسة من خلال الشرح والأمثلة والتدريب والتغذية الراجعة القائمة على قواعد مبرمجة.

## تشغيل محلي

```bash
pip install -r requirements.txt
streamlit run app.py
```

## النشر على Streamlit Community Cloud

ارفع الملفات `app.py` و`requirements.txt` إلى مستودع GitHub، ثم اختر المستودع والفرع `main` وملف التشغيل `app.py` في إعدادات التطبيق.

## حدود النسخة

- لا تتصل هذه النسخة بواجهة API ولا تستخدم نموذجا توليديا.
- الملاحظات آلية أولية تعتمد على مؤشرات عامة وليست حكما علميا نهائيا.
- لا ينبغي إدخال بيانات شخصية أو سرية.
